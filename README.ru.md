# Mimik

[English](./README.md) · **Русский**

**Пошаговые инструкции из действий в браузере.**

Запишите рабочий процесс, отредактируйте шаги и снимки экрана, затем экспортируйте инструкцию или пройдите её на исходном сайте.

## Начало работы

Откройте сайт и нажмите **Начать запись** на боковой панели Mimik. Выполните нужные действия: расширение создаст шаги со снимками экрана и выделенными элементами. Кнопка **Завершить запись** открывает готовую инструкцию для просмотра и редактирования.

Запись можно приостановить и продолжить. В редакторе доступны изменение текста, пометки и размытие на снимках, перестановка шагов, дополнительные заголовки и примечания, а также история версий.

## Русский язык

Язык интерфейса и язык AI-описаний задаются независимо.

**Интерфейс** использует язык интерфейса браузера. Для русского интерфейса нужен браузер с русской локалью и сборка расширения, содержащая `src/locales/ru.yml`. Простое добавление русского в список языков веб-страниц может не изменить язык интерфейса браузера. Английский остаётся языком по умолчанию для локалей без перевода.

**AI-описания**: откройте **Настройки → AI-описания → Язык описаний → Русский**, настройте провайдера и свой API-ключ. Настройки сохраняются автоматически. Инструкции модели и примеры описаний доступны на русском. Названия кнопок, полей, страниц и приложений должны оставаться такими, как на исходном сайте: например, «Нажмите кнопку Submit».

Без AI используются описания по шаблонам; их язык определяется локалью интерфейса браузера, а не настройкой AI.

Смена языка не переводит уже сохранённые инструкции автоматически. Отредактируйте существующий текст или воспользуйтесь доступными в редакторе инструментами AI. Наиболее простой способ проверить новые настройки — создать небольшую новую инструкцию.

## Две разные голосовые функции

### Голосовые комментарии: речь → текст

Эта функция соответствует **Voice Narration**. Вы говорите в микрофон во время записи, а Mimik распознаёт речь и связывает её с шагами. Сначала произнесите, что собираетесь сделать, затем выполните действие.

Настройте провайдера распознавания, ключ и микрофон, затем включите комментарии кнопкой микрофона на боковой панели. Проверка микрофона сама по себе не озвучивает готовую инструкцию.

При отсутствии отдельной настройки `voiceLanguage` код использует `aiLanguage`. Выбор русского языка описаний поэтому передаёт `ru` в существующий механизм распознавания. Явная отдельная настройка голоса имеет приоритет; пустое значение сохраняет автоматическое определение. Это не заменяет проверку распознавания с выбранным провайдером.

### Озвучивание видео: текст → речь

Эта функция соответствует **Video voice-over**. Она читает сохранённые описания шагов при экспорте видео; записывать свой голос не требуется.

Настройте **Озвучивание видео** и голос. В панели экспорта включите **Озвучивание** и экспортируйте видео. Длительность озвученных шагов подстраивается под аудио. Настроенный ключ не включает эту функцию автоматически.

Озвучивается существующий текст, а не его перевод. Для русскоязычного ролика сначала подготовьте русские описания. Выбор и качество голоса, доступ к API и работа аудиокодека проверяются в вашем браузере. Локализация не добавляет новый движок синтеза речи и не изменяет модели или ключи провайдеров.

## Экспорт и перенос

В проекте предусмотрены видео, GIF, PDF, DOCX, HTML, Markdown и редактируемый файл `.mimik`. Для переноса инструкции обратно в Mimik используется именно `.mimik`, если этот формат доступен в установленной версии.

Перед передачей инструкции просмотрите текст и снимки. Умное размытие не охватывает любой возможный источник данных на странице: содержимое iframe, Shadow DOM, текст внутри изображений и некоторые другие элементы требуют отдельной проверки. Размытие не применяется задним числом к ранее снятым кадрам.

В русских шаблонах вводимые значения заключаются в прямые двойные кавычки (`"значение"`). Это совместимо с существующим удалением коротких введённых значений при подготовке `.mimik` к отправке.

Перед рабочим использованием проверьте кириллицу в выбранных форматах экспорта, особенно в PDF. Перевод строк не меняет шрифты и не является отдельной проверкой всех средств экспорта.

## Сборка из исходников

Требования и актуальные правила разработки описаны в [CONTRIBUTING.md](./CONTRIBUTING.md). Используйте Node.js 22+ и версию pnpm, закреплённую в поле `packageManager` файла `package.json` (сейчас 10.32.1).

В корне репозитория:

```sh
pnpm install
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm build:firefox
```

Результат сборки Chrome находится в `.output/chrome-mv3/`, Firefox — в `.output/firefox-mv3/`. Для разработки доступны `pnpm dev` и `pnpm dev:firefox`.

В Chrome откройте `chrome://extensions`, включите режим разработчика и выберите **Загрузить распакованное расширение**, указав каталог сборки Chrome, а не корень исходников.

Не удаляйте прежнюю установленную копию до проверки сохранности и переноса инструкций. Локальная сборка и магазинная версия могут использовать разные идентификаторы и отдельные данные. Профиль, открываемый инструментами разработки, также может отличаться от вашего основного профиля.

## Данные и внешние сервисы

Инструкции и снимки сохраняются в браузере. У Mimik нет обязательной учётной записи или собственного сервера для хранения инструкций.

Дополнительные AI-функции отправляют текст или аудио выбранному провайдеру с использованием вашего ключа. Генерация описаний использует текстовый контекст страницы; распознавание речи отправляет аудио; озвучивание видео отправляет текст шагов. Эти обращения могут тарифицироваться провайдером. Значки сайтов загружаются через сервис Google, которому передаётся домен сайта.

Полная расшифровка речи хранится локально и не включается в экспорт как отдельная расшифровка. Однако слова, уже добавленные в описания шагов, входят в экспортируемые описания. Просмотрите их перед отправкой.

Дополнительные сведения: [Privacy policy](https://mimik.westpoint.io/privacy/).
